## Структура проекта

- `main.py` - точка входа в приложение.
- `database.py` - классы `Table`, `InMemoryDatabase` и исключение `DatabaseError`.
- `interface.py` - класс `ConsoleInterface` для консольного пользовательского интерфейса.
- `tests/test_database.py` - автоматизированные тесты логики базы данных.
- `tests/test_interface.py` - автоматизированные тесты вспомогательных методов интерфейса.
- `README.md` - описание проекта и инструкция по запуску.

## Реализованная функциональность

Система переписана с использованием классов и сохраняет возможности предыдущей лабораторной работы:

- создание нескольких таблиц;
- добавление записей;
- чтение всех записей таблицы;
- фильтрация записей по одному или нескольким полям;
- обновление записей по `id`;
- удаление записей по `id`;
- вывод списка таблиц;
- обработка ошибок при некорректном вводе, неизвестной таблице, неизвестном поле и несуществующей записи.

Дополнительно реализовано:

- класс пользовательского интерфейса `ConsoleInterface`;
- сортировка найденных записей по выбранному полю;
- выбор порядка сортировки: `asc` для возрастания или `desc` для убывания;
- автоматизированные тесты на базе стандартного модуля `unittest`.

При запуске автоматически создается демонстрационная таблица `books` с полями:

- `title`;
- `author`;
- `year`;
- `genre`.

## Запуск проекта

Откройте терминал в папке проекта:

```bash
cd C:\Users\user\PycharmProjects\DPopivanova
```

Запустите приложение:

```bash
python main.py
```

Если используется виртуальное окружение проекта:

```bash
.\.venv\Scripts\python.exe main.py
```

## Запуск тестов

Тесты запускаются командой:

```bash
python -m unittest discover -s tests
```

Если используется виртуальное окружение:

```bash
.\.venv\Scripts\python.exe -m unittest discover -s tests
```

Проверить покрытие тестами можно без установки внешних библиотек:

```bash
python run_tests_with_coverage.py
```

Скрипт запускает тесты и завершится с ошибкой, если суммарное покрытие файлов проекта ниже 80%.

## Пример фильтрации и сортировки

Фильтр по одному полю:

```text
author=Pushkin
```

Фильтр по нескольким полям:

```text
author=Pushkin, genre=poem
```

Сортировка:

```text
Sort by field: year
Direction: desc
```

Все данные хранятся только в оперативной памяти. После выхода из программы записи не сохраняются на диск.

## Структура проекта

- `main.py` - точка входа в приложение, выбор типа базы данных через аргументы командной строки.
- `database.py` - классы `Table`, `InMemoryDatabase`, `JsonFileDatabase`, `CsvFileDatabase` и исключение `DatabaseError`.
- `interface.py` - класс `ConsoleInterface` и фабрики для создания нужной реализации базы данных.
- `tests/test_database.py` - тесты таблиц, in-memory базы, JSON/CSV-хранилищ и индексов.
- `tests/test_interface.py` - тесты консольного интерфейса и выбора реализации базы данных.
- `run_tests_with_coverage.py` - запуск тестов и проверка покрытия без внешних библиотек.
- `.gitignore` - исключает служебные файлы, кеши и каталоги с тестовыми/рабочими данными.

## Реализованная функциональность

Сохранена объектно-ориентированная архитектура предыдущей лабораторной работы:

- создание нескольких таблиц;
- добавление записей;
- чтение записей с фильтрацией по одному или нескольким полям;
- сортировка записей по выбранному полю по возрастанию или убыванию;
- обновление записей по `id`;
- удаление записей по `id`;
- обработка ошибок при неверных данных, неизвестных таблицах, неизвестных полях и проблемах чтения/записи файлов;
- создание индексов по одному или нескольким полям таблицы.

## Реализации базы данных

`InMemoryDatabase` хранит таблицы только в оперативной памяти. После завершения программы данные пропадают.

`JsonFileDatabase` хранит каждую таблицу в отдельном `.json`-файле. В файле сохраняются имя таблицы, список полей, записи, следующий `id` и список индексированных полей.

`CsvFileDatabase` хранит каждую таблицу в отдельном `.csv`-файле. В CSV сохраняются служебные строки со структурой таблицы, список полей, записи, следующий `id` и индексированные поля.

Все реализации поддерживают одинаковый публичный интерфейс:

- `create_table`;
- `get_table`;
- `list_tables`;
- `add_record`;
- `read_records`;
- `update_record`;
- `delete_record`;
- `create_index`.

## Индексы

Индексы создаются методом `create_index` или через пункт меню `Create index`. При чтении записей таблица использует индекс, если фильтр содержит индексированное поле. Индексы обновляются при добавлении, изменении и удалении записей.

## Запуск проекта

По умолчанию приложение запускается с JSON-хранилищем в папке `data`:

```bash
python main.py
```

Запуск in-memory режима:

```bash
python main.py memory
```

Запуск JSON-хранилища с выбранной папкой:

```bash
python main.py json data_json
```

Запуск CSV-хранилища:

```bash
python main.py csv data_csv
```

Если используется виртуальное окружение проекта:

```bash
.\.venv\Scripts\python.exe main.py json data_json
```

## Запуск тестов

```bash
python -m unittest discover -s tests
python run_tests_with_coverage.py
```

Скрипт `run_tests_with_coverage.py` завершится с ошибкой, если суммарное покрытие файлов проекта ниже 80%.

Текущий результат проверки:

```text
Ran 60 tests
OK
Total coverage: 90.8%
```

## Пример работы

Фильтрация по нескольким полям:

```text
author=Pushkin, genre=poem
```

Сортировка:

```text
Sort by field: year
Direction: desc
```

Создание индекса:

```text
Index fields separated by commas: author, year
```

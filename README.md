## Структура проекта

- `main.py` - точка входа в приложение.
- `interface.py` - консольное меню, ввод данных, вывод таблиц и сообщений об ошибках.
- `database.py` - функции для работы с in-memory базой данных.
- `README.md` - описание проекта и инструкция по запуску.

## Реализованная функциональность

Поддерживаются следующие операции:

- создание нескольких таблиц;
- добавление записей в выбранную таблицу;
- чтение всех записей;
- фильтрация записей по одному или нескольким полям;
- обновление записей по `id`;
- удаление записей по `id`;
- вывод списка таблиц;
- обработка ошибок при неверном вводе, неизвестной таблице, неизвестном поле или несуществующей записи.

При запуске автоматически создается демонстрационная таблица `books` с полями:

- `title`;
- `author`;
- `year`;
- `genre`.

Также пользователь может создать собственные таблицы через пункт меню `Create table`.

## Запуск проекта

1. Откройте терминал в папке проекта:

```bash
cd C:\Users\user\PycharmProjects\DPopivanova
```

2. Запустите приложение:

```bash
python main.py
```

Если используется виртуальное окружение проекта, можно запустить так:

```bash
.\.venv\Scripts\python.exe main.py
```

## Пример фильтрации

Для поиска книг можно указать один фильтр:

```text
author=Pushkin
```

Или несколько фильтров:

```text
author=Pushkin, genre=poetry
```

Все изменения выполняются только в памяти. После выхода из программы данные не сохраняются на диск.
